## Sync policy

Sync is **fail-closed**: the michi-link checkout must match `UPSTREAM_LOCK.json`,
the contract paths must be clean, and the copied bundle must match its own
manifest (SHA-256). Use `--allow-contract-update` only during the explicit
contract-update procedure; the lock itself is never updated automatically.
